# District Fury

Original 2D beat'em up / brawler developed primarily with C++17+, raylib and CMake.

## Development target
PC first, then Web/WASM and Android.

## Current milestone
**V0.1 — Vertical Slice**

The first goal is a small, fully playable slice containing:
- Rayden
- movement
- basic attacks
- enemy
- damage/hitstun
- combo
- HUD
- win/game over
- reproducible build

## Repository structure

- `src/` — C++ source
- `assets/` — game assets
- `data/` — configurable gameplay data
- `tests/` — tests
- `docs/` — documentation
- `tasks/` — agent tasks
- `reports/` — build/QA/agent reports
- `.github/workflows/` — CI
